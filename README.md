# Controle Umidade Estufa Plantas
## Descrição do Problema
Sistema simples para monitorar a umidade relativa do ar em uma estufa e alertar sobre necessidade de irrigação.
## Requisitos
- Ler dados de sensores de umidade
- Verificar se a umidade está abaixo do mínimo (40%)
- Gerar alerta de irrigação se necessário
## Exemplo de Uso
Entrada: [45, 38, 52, 35]
Saída: Alertas para sensores 2 e 4
